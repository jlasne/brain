How it works

Every AI knows the same things. This one knows what you read.

Feed it articles, videos and documents. It keeps one position on each idea, with the evidence, the figures and the date behind it. Ask, and it answers from that.

01 · The life of a source

From a link to knowledge, in six steps.

  1. DropA link, a pasted text, or a document of any length.
  2. ReadRead whole, in parts of 18,000 characters, three at a time.
  3. FileEach idea joins the concept it belongs to, or opens a new one.
  4. RuleEvery claim that clashes with what you hold comes to you.
  5. RewriteEach position is worked out again from all its evidence.
  6. LinkNew concepts connect to the ones they build on.
02 · The principles

Seven rules every brain follows.

01

One brain per subject

An octopus carries 500 million neurons, and two thirds of them sit in its arms. Octopus works the same way: one brain per subject or per person, each organised on its own.

A question reads the brains that bear on it.

02

A position, with its proof

Each concept states what holds today. Under it sit the evidence, who said it and when, the figures, and any open conflict.

A new source re-derives the position from the whole list, so it reads as one view.

03

Every page is read

A 207 page document is read in parts, and every part is filed.

The AI sets the grain from the source itself: study material gets one concept per rule, an argument gets one concept per idea.

04

You rule the contradictions

When a source clashes with what a brain holds, you see both claims with their dates. You pick: keep both, the new one wins, or yours wins.

The position moves with your ruling, and the older view stays in the evidence, dated.

05

Ideas link to each other

Each concept links to up to 12 others it builds on, explains or is weighed against.

An answer follows those links, so it reaches the idea one step further.

06

Answers come from what you fed it

A question first reads every concept title, then opens the 30 that bear on it. The first sentence answers. Numbers sit inside, sources on one line underneath.

Pick the level: Normal, Educational, or Learning, which gives you the steps and leaves the answer to you.

07

Yours to keep

Every brain exports to plain markdown. The code is MIT licensed and runs on your own model key.

Any AI client can read the brains through one address: how to connect.

04 · Run your own

Open code, your key, your data.

As a web app

A Convex deployment holds the data. Any static host serves the pages.

git clone https://github.com/jlasne/brain cd brain && npm install # a deployment of your own npx convex dev # the key that pays for reading and rewriting npx convex env set OPENROUTER_API_KEY sk-or-... --prod npx convex deploy # the passphrase of each workspace npx convex run admin:setPass "{space:'octopus',pass:'...'}" --prod # optional: video links fetch their own transcript npx convex env set SUPADATA_API_KEY sd_... --prod

Then serve app/ as the site root. The repo carries a vercel.json that does it.

As files on your machine

A brain is a markdown folder you open in any editor.

cp -r brain/skill/brain ~/.claude/skills/brain

Then ask Claude Code for your first brain. Same rules, same export format as the web app.
